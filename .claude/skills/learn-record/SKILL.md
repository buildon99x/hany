# /learn-record — 작업 중 실수를 회고 지식으로 기록

방금 끝낸 작업에서 발생한 실수(잘못된 가정, 놓친 케이스, 거짓 안전감을 준 테스트 등)를 `docs/learn/lesson_{YYYY-MM-DD}_{slug}.md` 한 파일에 일반화 가능한 회고로 남긴다. Quality Note의 follow-up 과는 결이 다르다 — 여기는 "다음 비슷한 작업에서 같은 함정을 즉시 알아채기 위한 메모"다.

## 발동 조건
**슬래시 커맨드 진입 전용.** 사용자가 `/learn-record` 를 명시적으로 호출했을 때만 인보크한다. 자연어("실수 기록해줘", "lesson 남겨" 등)로는 자동 발동하지 않는다 — 사용자 의도를 추정해서 회고를 임의 생성하지 않기 위함.

## 입력
- `$ARGUMENTS` (선택): 슬러그 힌트(예: `frontend-cache-overrides-backend-reset`). 비면 대화 컨텍스트에서 추출 후 사용자에게 1줄로 제안.

## 산출 규약

파일 경로: `docs/learn/lesson_{YYYY-MM-DD}_{slug}.md`
- 날짜: 시스템의 오늘 날짜(`CLAUDE.md` 의 `currentDate` 또는 `date +%F`).
- 슬러그: kebab-case, 영문 소문자, 6 단어 이내. 패턴이 드러나는 명사구(예: `debounced-timer-survives-cache-invalidation`).
- 한 파일 = 하나의 실수 + 일반화. 여러 실수가 묶여 있으면 분리해 별도 파일로.

본문 섹션(필수, 순서 고정):

1. **메타 라인** — 날짜, 관련 커밋(SHA short), 재현 사례(사용자 시점 1줄).
2. **무엇을 놓쳤는가** — 1차 시도가 왜 충분해 보였는지 + 실제 실패 흐름. ASCII 다이어그램이 도움되면 코드펜스로.
3. **일반화** — 이 코드베이스에서 같은 함정이 다시 나올 수 있는 위치를 표/목록으로 매핑. 가능한 한 grep 가능한 식별자(파일·심볼·IPC 이름)로.
4. **다음 작업 체크리스트** — 같은 류의 작업을 시작할 때 즉시 적용할 항목. 각 항목은 "확인 가능한 명령/검증"을 포함.
5. **참고 코드** — 실제 수정 위치(`path:line` 또는 함수명)로 링크.
6. **안티패턴** — `❌` 로 시작하는 1줄 금지 패턴 묶음.

색인: `docs/learn/README.md` 의 색인 표에 한 줄 추가(날짜 내림차순 유지).

## 실행 절차

1. `docs/learn/README.md` 와 디렉토리의 기존 lesson 파일들을 `Read`/`ls` 로 확인 — 동일 슬러그 충돌 / 동일 패턴 중복 회고 방지.
2. 직전 대화 컨텍스트에서 다음을 추출:
   - 1차 시도(불완전했던 fix)와 2차 시도(실제 해결)의 커밋 SHA.
   - 사용자가 보고한 재현 사례 원문.
   - "왜 통과했는데도 버그가 살아남았는지" 의 인과 사슬.
3. 슬러그 / 메타 / 6 섹션 초안을 작성해 사용자에게 보여주고 1회 확인을 받는다(이 스킬은 회고 품질이 핵심이므로 무확인 저장 금지).
4. 확인 후 `Write` 로 파일 생성, `Edit` 로 `docs/learn/README.md` 색인 갱신.
5. 커밋(사용자가 명시 요청 시): `docs(learn): record {slug} lesson` 메시지. 푸시는 명시 요청에만.

## 작성 원칙

- **고유명사가 아니라 패턴**으로 적는다. "이 PR 에서 X 컴포넌트 버그" 가 아니라 "Backend 권위 + Frontend 캐시 + write-back IPC 가 공존할 때의 stale 회귀".
- **거짓 안전감의 출처**를 반드시 기명한다(통과한 단위 테스트, 정상으로 보인 IPC, 충분해 보인 backend 수정 등).
- 체크리스트 항목은 **다음 작업자가 grep 한 번으로 검증 가능**한 형태여야 한다.
- 코드 인용은 최소한. 회고는 "다음에 무엇을 먼저 의심할까" 가 본체다.
- `CLAUDE.md` Planning Rules 와 동일한 톤: 간결, 1–2 줄 요약 우선.

## 슬래시 커맨드와의 관계
`/learn-record` 만이 진입점. 자연어 진입 경로 없음.
