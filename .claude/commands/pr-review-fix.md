# /pr-review-fix — PR 리뷰 기반 자동 수정

사용 형식: `/pr-review-fix [pr-number]`

`$ARGUMENTS` 가 PR 번호. 비면 현재 브랜치에 연결된 PR 을 자동 탐지(0/2+건이면 사용자에게 묻는다).

## 처리 절차

1. `.claude/skills/pr-review-fix.md` 를 `Read` 로 로드.
2. 스킬의 §0(사전 게이트) → §1(리뷰 수집) → §2(분류) → §3(계획 승인 게이트) 까지 순차 진행.
3. §3 에서 사용자 명시 승인 후 §4(구현) → §5(검증) → §6(푸시) → §7(답글) 을 연속 수행.
4. B 카테고리(모호·아키텍처 영향)는 임의 구현 금지 — 답글 초안만 준비, 사용자 동의 시에만 게시.

세부 규약(분류 기준, 검증 명령, 푸시 재시도, 답글 템플릿, 가드레일)은 모두 `.claude/skills/pr-review-fix.md` 단일 소스를 따른다.

## 예시
- `/pr-review-fix 155`
- `/pr-review-fix` (현재 브랜치 PR 자동 탐지)

$ARGUMENTS
